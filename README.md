# Skills

Agent Skill 集合。每个 skill 都在独立目录中，通过目录内的 `SKILL.md` 使用。

| Skill | 用途 |
| --- | --- |
| [orca-orchestrator](orca-orchestrator/SKILL.md) | 使用 Orca 编排和监督多个编码 Agent |
| [design-with-clarity](design-with-clarity/SKILL.md) | 从用户理解和内容关系出发，设计、改进与评审 UI |

安装指定 skill：

```bash
npx skills add dnslin/skills --skill design-with-clarity
```

各 skill 的参考资料、具体用法见对应目录的 README 和 SKILL.md。
